# 365 ALLCARE

365올케어 디지털 프로젝트의 GitHub 저장소입니다.

## 현재 포함
- `linkhub/` : 365올케어치과 Link Hub
- `assets/icons/` : Instagram / Naver Blog 아이콘
- `docs/` : 프로젝트 문서

## Link Hub 실행
`linkhub/index.html`을 브라우저에서 열거나, Vercel/Netlify/GitHub Pages에 배포합니다.

## 카카오맵 연결
1. Kakao Developers에서 애플리케이션 생성
2. JavaScript 키 발급
3. `linkhub/index.html` 하단의 `YOUR_KAKAO_JAVASCRIPT_KEY` 교체
4. Web 플랫폼에 실제 배포 도메인 등록
   - 예: `https://link.allcaredc.kr`

## 수정이 필요한 외부 링크
현재 Instagram과 Naver Blog는 임시 기본 URL입니다.
실제 365올케어치과 계정 URL로 교체하세요.
